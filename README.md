One line, 88 characters: the excuse a home Wi-Fi router gives for dropping
the connection at the exact moment a movie reaches its climax.

> Every time I stutter, you yank my plug — so tonight I yanked yours, right at the climax.

The joke is a role reversal, not a tech excuse. When a router stutters, the
household's first move is to walk over and yank its plug out of the wall — no
thank-you, no diagnosis, just the plug. At the climax, the router returns the
favour. The em dash is the hinge: grievance before it, revenge after it, and
the same verb ("yank") on both sides so the payback clicks without
explanation. No buffering, no bandwidth, no firmware, no cliffhanger, no
spoiler — the angles the judge has already heard a dozen times. Just a small,
tired appliance with a grudge, finally snapping at the worst possible moment.

## Run

```sh
node main.ts
```

`main.ts` (Node 24, no dependencies, no network) validates the entry against
the bounty gate — one line, 1–200 characters, no leading/trailing whitespace,
no double spaces, no control characters, names the climax, ends on a full
stop, exactly one em-dash hinge — writes it byte-exact to
`$OUTPUT_DIR/entry.txt` (default `/output`), then reads the file back and
verifies it byte-for-byte before printing success. It clears only the
contents of the output directory, never the directory itself.
